# Letter Loom

Игры для детей 3–7 лет со снежным барсом Ирби: буквы, речь, счёт, память и логика. Языки: русский, кыргызский, узбекский, английский.

## Как запустить в садике без интернета

Схема такая: игра работает на ноутбуке воспитателя, а планшеты подключаются к нему по Wi‑Fi.

1. **Дома, пока есть интернет**
   - Запустите сервер: `cd backend && npm start`. Затем соберите игру: `cd frontend && npm run build`.
   - Откройте игру. Нажмите «Для взрослых», решите пример и попадёте в режим учителя.
   - Нажмите «Скачать» в блоке «Работа без интернета». Это примерно 1600 фраз на язык и около 20–30 минут.
   - Повторите для каждого нужного языка: сначала переключите язык в меню, потом снова нажмите «Скачать».
   - Голос сохранится в кэше сервера (`backend/.cache/tts`). Картинки уже лежат в `backend/images`.
2. **Один раз создайте сертификат для https:** `bash backend/scripts/make-cert.sh`, затем перезапустите сервер. Https нужен, чтобы на планшетах работал микрофон и игра сохранялась на самом планшете.
3. **В садике**
   - Подключите ноутбук и планшеты к одной сети Wi‑Fi. Интернет не нужен.
   - На каждом планшете откройте в Chrome `https://<IP ноутбука>:5443`.
   - Браузер предупредит о сертификате: нажмите «Дополнительно», затем «Перейти на сайт».
   - Добавьте игру на главный экран (меню Chrome → «Добавить на главный экран»).

### Что работает без интернета

- Все игры, картинки и звуки.
- Голос Ирби для всех заданий, если пакет скачан заранее. Фразы с именем ребёнка («Привет, Малика!») заранее не скачать, без интернета их произносит голос планшета.
- Вход ребёнка по имени: профиль сохраняется на устройстве.

### Если планшет должен работать совсем один, без ноутбука

Игра умеет полностью сохраняться на планшете: service worker хранит приложение, картинки и голос. Но браузер разрешает это только по настоящему https. Есть два способа:

- установить на планшет корневой сертификат (например, через `mkcert`);
- один раз открыть игру с сервера, у которого есть настоящий https-адрес, и скачать голос в режиме учителя.

## Приватность

- О детях хранится только имя на сервере, для звёзд. Прогресс и уровни лежат только в памяти устройства.
- Микрофон лишь измеряет громкость: звук не записывается, не сохраняется и никуда не отправляется.
- Рекламы и покупок нет.

## Для разработчика

- Сервер: `backend/ч.js` (Express + PostgreSQL), порт 5001, https на 5443, если есть `backend/certs`.
- Клиент: `frontend` (React). Игры лежат в `src/components/*Game.js`, общий каркас в `GameShell.js`, режим учителя в `TeacherPanel.js`.
- Офлайн: `frontend/public/service-worker.js`. Голосовой пакет собирают функции `voicePhrases()` каждой игры (`src/lib/voicePack.js`).
- Тесты: `cd frontend && CI=true npx react-scripts test --watchAll=false`.
